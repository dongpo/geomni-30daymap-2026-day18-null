  - heading "Mobile Broadband Coverage (Global - 5 km) - 2026 Release" [level=5]
  - generic: Description
  - paragraph: This 2026 release is a derived raster product representing the proportion of each 5 km grid cell covered by mobile broadband service. It was produced from the original approximately 260 m binary mobile broadband coverage raster compiled from GSMA Mobile Coverage Explorer and OpenCellID-based coverage information.
  - paragraph: The source raster was converted to a binary 1/0 grid and resampled to 5 km using average resampling in EPSG:3857. Output values range from 0 to 1, where 0 indicates no detected coverage, 1 indicates full coverage, and intermediate values indicate partial coverage within the 5 km cell. The derived no-data value is 0
  - paragraph: Mobile Coverage is released annually in January each year. The latest data source release is named 2026. Any operator data received up to the end of the year 2025 is included in this release.

    - paragraph: Tower locations are derived from data collected from mobile phone users and so the coverage tends to be concentrated along routes and built-up areas;

    - paragraph: The derived coverage does not take account of obstructing factors such as terrain variations. Because of these limitations, the OCI data should be viewed as an approximation only.
